# 🏥 LangGraph Medical Symptom Classifier

This project is a simple AI-powered medical assistant built using **LangGraph** and **LLMs**.

It classifies user-reported symptoms into one of the following categories:
- **General**
- **Emergency**
- **Mental Health**

## 🚀 How It Works
1. User enters a symptom
2. LLM classifies the symptom
3. LangGraph routes the request to the appropriate node
4. User receives guidance on which medical department to consult

## 🧠 Technologies Used
- Python
- LangGraph
- LangChain
- Large Language Models (LLMs)
- Google Colab

## 📌 Example
**Input:** `I have fever`  
**Output:** `General`
